## Что понадобится

- Считыватель **IronLogic Z-2 USB** (в диспетчере устройств он выглядит как
  `USB\VID_0403&PID_1234`).
- **Python 3.12** или новее.
- Списки групп в Excel — обычные, из деканата. Свой формат программа
  не требует.
- Windows 10 или 11.

## Шаг 1. Драйвер считывателя

### Почему просто так не ставится

У IronLogic свой идентификатор устройства — `PID 1234` вместо стандартного
FTDI `6001`. Windows подбирает драйвер строго по этому идентификатору, а в
сертифицированном пакете FTDI объявлены только их собственные. Отсюда ответ
«подходящий драйвер не найден».

Родной пакет IronLogic нужный идентификатор содержит, но подписан по SHA‑1
в 2017 году, и Windows 10/11 такую подпись отвергает:

```
Driver package INF file hash is not present in catalog file
Driver package appears to be tampered, and Code Integrity is enforced
```

Отключить проверку подписи мешает Secure Boot. Поэтому используется приём
ниже: современный подписанный пакет навязывается устройству вручную.

### Установка

Драйвер лежит в релизе: файл `ironlogic-driver-2.12.36.20.zip`. Распакуйте
его куда угодно и запомните путь.

**Сначала воткните считыватель в USB.**

> Установка состоит из **двух этапов**, и второй делается над **другим**
> устройством. Если остановиться после первого, COM‑порт не появится, и будет
> казаться, что ничего не вышло. Это самая частая ошибка.

#### Этап 1 — шина

1. `Win+X` → **Диспетчер устройств**
2. Раскройте **«Другие устройства»** → там `USB IronLogic RFID Adapter`
   с жёлтым значком
3. Правой кнопкой → **Обновить драйвер** → **Найти драйверы на этом компьютере**
4. Внизу окна: **«Выбрать драйвер из списка доступных драйверов на компьютере»**
5. Если спросит тип устройства — **«Показать все устройства»**
6. Кнопка **«Установить с диска…»** → «Обзор» → файл **`ftdibus.inf`**
   из распакованного архива
7. **Снимите галку «Только совместимые устройства»**
8. Выберите **`USB Serial Converter`** → Далее
9. Windows предупредит, что драйвер может не подойти устройству. Это
   ожидаемо — соглашайтесь.

Готово, если в разделе **«Контроллеры USB»** появился `USB Serial Converter`.

#### Этап 2 — порт

10. Появится **новое** неизвестное устройство — `USB Serial Port`
11. Повторите с ним пункты 3–9, но укажите **`ftdiport.inf`**
    и выберите модель **`USB Serial Port`**

Готово, если в разделе **«Порты (COM и LPT)»** появился `USB Serial Port (COM3)`
или с другим номером.

### Как избавиться от ручной установки навсегда

Если считыватель придётся ставить на много компьютеров, проще один раз
перепрошить его идентификатор с `1234` на стандартный FTDI `6001` утилитой
**FT‑Prog**. Для `6001` Windows ставит драйвер сама — воткнул и работает.
У IronLogic есть официальная инструкция «Восстановление исходного (FTDI) PID».

Две оговорки: перепрошивать надо на компьютере, где драйвер **уже** работает
(FT‑Prog общается с чипом через него), и фирменные программы IronLogic после
смены идентификатора могут перестать видеть устройство.

## Шаг 2. Установка программы

```powershell
py -3 -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt
```

Проверьте, что всё на месте:

```powershell
venv\Scripts\python.exe -m rfid doctor
```

Должно быть примерно так:

```
[ OK ] считыватель найден: COM3
[ OK ] pyserial установлен
[ OK ] openpyxl установлен
```

Дальше для краткости пишется просто `rfid`. Чтобы так работало, пользуйтесь
обёрткой `rfid.cmd` из папки проекта:

| Оболочка | Как звать |
|---|---|
| PowerShell | `.\rfid.cmd doctor` |
| cmd.exe | `rfid.cmd doctor` |
| откуда угодно | `venv\Scripts\python.exe -m rfid doctor` |

## Шаг 3. Списки групп

**Папка `tables` — это корень. Внутри неё папка на каждый предмет, а в папке
предмета — файлы групп, по одному на группу.**

```
tables/
  АСУ/
    Список группы 1.xlsx
    Список группы 2.xlsx
  Матанализ/
    Список группы 1.xlsx
```

Имя папки и есть название предмета — как назовёте, так и будет в программе.
Папки создаёте вы сами в проводнике; программа их не трогает.

### Какой нужен файл

Обычный список из деканата. Программа подстраивается сама:

- **Группа** берётся из строки над шапкой — «Группа 1000000/10001» или просто
  «ИКНК 1000000/10001». Если такой строки нет, возьмётся имя файла.
- **Шапка** ищется по ячейке со словом «ФИО».
- **Студенты** — подряд ниже шапки, до первой пустой строки.
- Всё, что ниже списка (примечания, «Староста: …»), не трогается.
- Номера в первой колонке могут быть формулами — они не перезаписываются.
- Колонки с датами дописываются справа от ФИО.

Проверить, что файлы видны:

```powershell
rfid subjects
```

```
АСУ
   1000000/10001       25 чел.   Список группы 1.xlsx
   1000000/10002       17 чел.   Список группы 2.xlsx
```

Если файл лежит в самой `tables`, а не в папке предмета, программа скажет,
что он не используется.

## Шаг 4. Привязка карт (один раз)

На карте записан только номер — ни фамилии, ни группы там нет и быть не может.
Связь «карта → человек» создаётся один раз, когда владелец карты стоит рядом.

```powershell
rfid enroll
```

Программа спросит предмет и покажет **всех студентов одним списком** со сквозной
нумерацией. Студент прикладывает карту, вы вводите **только номер** — фамилию
набирать не нужно, группа подставится сама.

```
  1000000/10001
      1. Иванов Иван Иванович
      2. Петрова Анна Сергеевна        карта есть
     ...
  1000000/10002
     26. Сидоров Пётр Петрович

  Приложите карту студента…
  Карта прочитана: A10007002A
  Номер студента (Enter — пропустить, 0 — закончить): 1
  Привязано: Иванов Иван Иванович (1000000/10001)
```

Рядом с уже привязанными стоит пометка «карта есть». Если приложить знакомую
карту, программа не переспросит, а покажет, за кем она закреплена.

Посмотреть все привязки: `rfid students list`.
Снять ошибочную: `rfid students remove <код карты>`.

## Шаг 5. Отметка на паре

```powershell
rfid scan
```

Спросит предмет, дальше студенты прикладывают карты:

```
 ОТМЕЧЕН            Иванов Иван Иванович        1000000/10001  09:02
 УЖЕ ОТМЕЧЕН        Петрова Анна Сергеевна                    с 09:01
 НЕИЗВЕСТНАЯ КАРТА  B20008002B  (008,43)                       09:05
```

- **зелёное** — отметка записана;
- **жёлтое** — этот студент уже отмечался на этой паре сегодня;
- **красное** — карта не привязана. Отметка всё равно сохраняется, очередь
  не тормозится; привяжете позже, и она станет именной задним числом.

Выход — `Ctrl+C`. При выходе время прихода проставляется в файлы групп.

### Что считается опозданием

Отметка позже чем через **10 минут** после начала пары. Начало определяется
по первому приложившему карту.

Пары распознаются автоматически: занятие идёт 1 час 40 минут, перемена
20 минут. Поэтому если у двух групп одного предмета пары в разное время,
у каждой будет свой отсчёт, а приложенная на перемене карта не испортит
следующую пару.

Опоздавшие подсвечиваются в таблице жёлтым.

## Шаг 6. Отчёты и выгрузка

```powershell
rfid report
```

```
АСУ — 22.09.2026
──────────────────────────────────────────────────────────
ФИО                        Группа          Время    Статус
Иванов Иван Иванович       1000000/10001   09:02    отметился
Петрова Анна Сергеевна     1000000/10001   —        НЕ отметился
──────────────────────────────────────────────────────────
1000000/10001   1/2  (50%)
```

Видно и тех, кого не было — иначе непонятно, кого не хватает.

```powershell
rfid export
```

Перезаписывает отметки во всех файлах групп. Делать это специально обычно не
нужно: после каждой пары запись происходит сама. Команда нужна, если файл был
открыт в Excel и запись не прошла, или если вы что-то поправили в таблице
руками и хотите вернуть как в базе.

### Как выглядит результат

В ваш файл справа от ФИО дописывается колонка с датой:

| № | ФИО студента | 20.09 | 22.09 | 24.09 |
|---|---|---|---|---|
| 1 | Иванов Иван Иванович | 09:02 | 09:04 | 09:01 |
| 2 | Петрова Анна Сергеевна | 09:03 | **09:15** | — |
| 3 | Сидоров Пётр Петрович | — | — | — |

Время — когда приложил карту, прочерк — не было, жёлтым — опоздал.

> **Важно понимать.** Отметки хранятся в базе `data/attendance.db`, а файлы
> Excel — её отражение. Если удалить колонку с датой, следующий `rfid export`
> её восстановит. Обратное не работает: время, вписанное в Excel руками,
> в базу не попадёт и при следующей выгрузке пропадёт.

## Если что-то пошло не так

### Считыватель не найден

```powershell
rfid ports
```

Если считыватель в списке есть, но программа его не видит — запустите с явным
портом: `rfid scan --port COM3`.

Если считывателя нет:
- воткнут ли он в USB;
- есть ли в диспетчере устройств `USB Serial Port` в разделе «Порты»;
- сделаны ли **оба** этапа установки драйвера (см. шаг 1).

### Файл открыт в Excel

```
файл открыт в Excel — закройте и повторите. Отметки в базе целы.
```

Закройте файл и выполните `rfid export`. Ничего не потеряно: отметки
хранятся в базе, а файл — лишь её отражение.

### «не найден в списке»

```
не найден в списке: Иванов Иван Иванович
```

Значит фамилия в файле изменилась, а привязка карты осталась на прежнюю.
Связь держится на совпадении ФИО (регистр, «ё» и лишние пробелы не важны).
Лечится повторной привязкой карты через `rfid enroll`.

### Начать с чистого листа

```powershell
rfid reset marks    # удалить отметки, привязки карт оставить
rfid reset cards    # снять привязки, отметки станут безымянными
rfid reset all      # всё
```

Файлы групп в `tables` эти команды не трогают никогда.

### Считыватель отключился посреди пары

Программа не падает: она скажет, что устройство недоступно, и будет
переподключаться сама. Воткните обратно и продолжайте.

### Не помню команду

Запустите без аргументов — откроется меню:

```powershell
rfid
```

```
  Учёт посещаемости по RFID-картам
  ────────────────────────────────────────────
    1. Отмечать студентов
    2. Привязать карты к студентам
    3. Кто пришёл сегодня
    4. Чья это карта
    5. Предметы и группы
    6. Кому какая карта принадлежит
    7. Заполнить файлы групп
    8. Проверить оборудование
    0. Выход       (или Ctrl+C)
```

Меню работает по кругу: после действия возвращает к себе. Выход — `0`
или `Ctrl+C`. Из любого выбора можно вернуться назад тем же нулём.
