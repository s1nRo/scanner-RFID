RFID Журнал — версия для флешки
===============================

Всё нужное лежит в этой папке, Python и установка не нужны:

  RFID-Scanner.exe  — программа
  data\             — база: студенты, привязки карт, отметки (появится сама)
  tables\           — папки предметов со списками групп .xlsx
  driver\           — драйвер считывателя IronLogic
  portable.txt      — метка «данные хранить здесь». Не удаляйте.

Копируйте на флешку папку целиком. База и списки едут вместе с ней:
на любом компьютере открываются те же отметки и привязки карт.

Первый запуск на новом компьютере
---------------------------------

1. Создайте в папке tables папку с названием предмета и положите в неё
   списки групп. Без предмета кнопка сканирования не работает.
2. Воткните считыватель в USB.
3. Запустите RFID-Scanner.exe, выберите предмет, нажмите
   «Начать сканирование». Если программа уже была открыта, сперва нажмите
   «Загрузить изменения» на вкладке «Студенты и карты».
4. Если драйвера на этом компьютере нет, программа предложит поставить
   его из папки driver. Согласитесь, Windows спросит права администратора
   — подтвердите.

Права администратора нужны один раз на каждом компьютере (и ещё раз, если
подключить туда другой считыватель): без них
Windows драйвер не ставит, обойти это нельзя. Дальше считыватель
работает на этом компьютере сразу. Если прав нет — попросите
администратора один раз запустить RFID-Scanner.exe и нажать
«Начать сканирование».

Драйвер подписанный (FTDI CDM 2.12.36.20), Secure Boot отключать не нужно.

Если что-то пошло не так
------------------------

  «COM-порт не появился» — выньте считыватель, воткните снова и нажмите
  «Начать сканирование» ещё раз.

  Отметки не попали в Excel — закройте таблицы в Excel: пока файл открыт,
  Windows не даёт его записать. Отметки при этом уже в базе: закройте файл
  и нажмите «Записать в таблицы» на вкладке «Студенты и карты».

  Не вынимайте флешку, пока идёт сканирование или программа открыта:
  база пишется прямо на неё.
